# News Time — APKs oficiais

Aplicativo Android com notícias de economia e política em um feed de texto: título, resumo da fonte e link original.

[Baixar a versão mais recente](https://github.com/Naremancil/News-hub-releases/releases/latest)

## Instalar

1. Abra a última versão e baixe o arquivo `News-Time-*.apk` no celular.
2. Abra o arquivo e permita a instalação pela fonte usada, se solicitado pelo Android.
3. No News Time, abra o ícone de Atualizações e permita os avisos e a instalação de atualizações.

Requer Android 7 ou posterior. Não exige conta ou servidor. A partir de 0.2.0, consulta novas versões aproximadamente a cada hora, inclusive em segundo plano. O Android pode adiar a consulta e pedir confirmação para instalar.

Para quem já instalou um APK oficial anterior a 0.2.0, instale a versão nova manualmente uma vez. As atualizações seguintes usam o mecanismo do aplicativo. Uma versão de teste com outra assinatura não pode ser substituída diretamente pelo APK oficial.

Este repositório contém somente os APKs assinados, instruções e metadados de atualização. O código-fonte é mantido em repositório privado. Nenhuma credencial é necessária no celular.

## Arquivos de cada versão

- `.apk`: aplicativo para instalar e compartilhar.
- `update.json`: versão, endereço, tamanho e SHA-256 usados pelo atualizador.
- `SHA256.txt`: soma de verificação.
- `LEIA-ME.txt`: instruções de instalação.
